# RT1176 MicroMod SOM

An NXP i.MX RT1176 (Cortex-M7 1 GHz + Cortex-M4 400 MHz) on a MicroMod processor card (M.2 2222 Key E). It uses the SparkFun MicroMod Teensy pinout, so it drops into the RaceLink intercom carrier in place of the MicroMod Teensy.

- **Status:** stage 3 (layout) fully routed, DRC clean in KiCad 7 (0 unconnected, 0 clearance errors). Next: hand-tidy USB and crystal traces, GND pours, then stage 4 (fab files).
- **Schematic:** [docs/schematic.pdf](docs/schematic.pdf). Generated by `tools/schgen.py`; regenerate rather than editing in KiCad.
- **Design decisions and open items:** [docs/DESIGN.md](docs/DESIGN.md)
- **Pin map:** [docs/PINOUT.md](docs/PINOUT.md). Generated from `tools/pinmap.py`; don't edit by hand.
- **Floorplan:** [docs/floorplan_v1.png](docs/floorplan_v1.png)

## Tools

KiCad 7 + Python, the same toolchain as the intercom carrier.

| Script | Does |
|---|---|
| `tools/pinmap.py` | Single source of truth: MicroMod pin -> RT1176 pad and function |
| `tools/verify.py` | Checks the pin map against NXP's pin-mux data (Zephyr hal_nxp) and the RT1176 ball map: function exists on the pad, no pad used twice, every Teensy pin covered |
| `tools/mktable.py` | Regenerates docs/PINOUT.md |
| `tools/optimize_pins.py` | Picks RT1176 pads for each MicroMod signal to keep ball-to-finger routes short |
| `tools/floorplan.py` | Regenerates the floorplan drawing |
| `tools/libgen.py` | Builds `lib/`: RT1176 symbol (6 units, from the ball map), MicroMod card symbol and edge-finger footprint |
| `tools/schgen.py` | Builds the KiCad 7 schematic (root + 4 sheets) from one parts/nets table |
| `tools/schcheck.py` | Exports the netlist with kicad-cli and checks it against the design table, the pin map and NXP's rail rules |

Regenerate everything: `python3 tools/libgen.py && python3 tools/schgen.py && python3 tools/schcheck.py`
